# Contributing

Thank you for contributing to NewBridge.

1. Open an issue for significant behavior changes.
2. Create a focused branch.
3. Add or update tests for behavior changes.
4. Run `npm run build`, `npm test` and `npm run lint`.
5. Do not commit credentials, instance URLs containing customer identifiers, or production data.
6. Keep core features based on documented ServiceNow APIs whenever possible.
7. Document compatibility assumptions.

All contributors must follow CODE_OF_CONDUCT.md.
